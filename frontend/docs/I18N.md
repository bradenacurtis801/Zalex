# Internationalization (i18n) Guide

This document explains how to use the internationalization system in the SabioDocs frontend.

## Overview

The frontend uses `react-i18next` and `i18next` for internationalization, supporting English (en) and Spanish (es) locales.

## File Structure

```
frontend/
├── locales/
│   ├── en.json          # English translations
│   └── es.json          # Spanish translations
├── lib/
│   └── i18n.ts          # i18n configuration
├── contexts/
│   └── LanguageContext.tsx  # Language context provider
└── components/
    └── ui/
        └── LanguageSwitcher.tsx  # Language selector component
```

## Usage

### In Components

1. Import the `useLanguage` hook:

```tsx
import { useLanguage } from '@/contexts/LanguageContext'

export default function MyComponent() {
  const { t, language, changeLanguage } = useLanguage()
  
  return (
    <div>
      <h1>{t('common.appTitle')}</h1>
      <p>{t('auth.signIn')}</p>
    </div>
  )
}
```

### Translation Keys

Translation keys are organized by feature/domain:

- `common.*` - Common UI elements (buttons, labels, etc.)
- `auth.*` - Authentication related
- `navigation.*` - Navigation menu items
- `dashboard.*` - Dashboard page
- `upload.*` - Upload page
- `categories.*` - Categories page
- `search.*` - Search page
- `user.*` - User management
- `document.*` - Document viewing
- `reclassification.*` - Document reclassification
- `language.*` - Language switcher

### Adding New Translations

1. Add the English translation to `locales/en.json`:

```json
{
  "myFeature": {
    "title": "My Feature Title",
    "description": "My feature description"
  }
}
```

2. Add the Spanish translation to `locales/es.json`:

```json
{
  "myFeature": {
    "title": "Título de Mi Función",
    "description": "Descripción de mi función"
  }
}
```

3. Use in your component:

```tsx
const { t } = useLanguage()
<h1>{t('myFeature.title')}</h1>
```

### Changing Language Programmatically

```tsx
const { changeLanguage } = useLanguage()

// Change to Spanish
changeLanguage('es')

// Change to English
changeLanguage('en')
```

### Language Persistence

The selected language is automatically saved to `localStorage` and persists across page reloads.

## Language Switcher

The `LanguageSwitcher` component is already integrated into the `Header` component. It appears in both desktop and mobile navigation.

## Best Practices

1. **Always use translation keys** - Never hardcode user-facing strings
2. **Use descriptive keys** - Use namespaces and descriptive key names (e.g., `auth.signIn` not `s1`)
3. **Keep translations in sync** - When adding new keys, add them to both `en.json` and `es.json`
4. **Use interpolation for dynamic content** - For values that change, use i18n interpolation:

```tsx
// In translation file:
{
  "welcome": "Welcome, {{name}}!"
}

// In component:
t('welcome', { name: user.name })
```

5. **Pluralization** - Use i18next's pluralization features for plural forms:

```json
{
  "items": "{{count}} item",
  "items_plural": "{{count}} items"
}
```

## Testing

To test different languages:

1. Use the language switcher in the header
2. Or programmatically: `changeLanguage('es')` in browser console
3. Refresh the page to verify persistence

## Adding New Languages

To add a new language (e.g., French):

1. Create `locales/fr.json` with translations
2. Update `lib/i18n.ts` to include the new language:

```ts
const resources = {
  en: { translation: enTranslations },
  es: { translation: esTranslations },
  fr: { translation: frTranslations }, // Add this
}
```

3. Update `LanguageSwitcher.tsx` to include the new option
4. Update the `Language` type in `LanguageContext.tsx` if using TypeScript
